# Aliengotchi 🎮

Tamagotchi alienígena con estética retro Wii. Proyecto desarrollado para aprender Git, GitHub, JavaScript y despliegue continuo.

## 🚀 Tecnologías
- HTML5, CSS3, JavaScript ES6+
- Git y GitHub (ramas, pull requests, conventional commits)
- LocalStorage para persistencia de partida
- GitHub Pages para despliegue

## 🎲 Cómo jugar
- **Alimenta, duerme y juega** con tu alien para mantener hambre, energía y diversión.
- Cada 6 segundos las estadísticas bajan ligeramente (decaimiento lento).
- El alien cambia de imagen según su estado (normal, enfadado, somnoliento, triste, muerto).
- **Arrastra y lanza** al alien: rebota por la habitación y ganas puntos de diversión (hasta +30).
- **Minijuegos**: Piedra Papel Tijeras, Memotest, Simón Dice, y **Adivina el número**.
- **Cama y nevera interactivas**: al hacer clic en la cama o lámpara, el alien duerme (la habitación se oscurece). Al hacer clic en la nevera, eliges comida que afecta a las estadísticas.
- **Selector de 3 alienígenas** al inicio: verde, azul o rojo.
- **Música de fondo** se activa con el primer clic del usuario.
